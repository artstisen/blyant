# Changes

## v0.1.0 (in progress)
- **Blyant starts from Marbles v1.5.3**: the program, the project and its files are renamed from Marbles to Blyant (the namespace, `Blyant.sln`, the folders `Blyant` and `Blyant.Tests`, the program `Blyant` / `Blyant.exe`, the archives `Blyant-0.1.0-*.zip` and the language pack). The built-in logo spells BLYANT, and the color scheme _Marbles Quest_ is now _Blyant Quest_.
- **No encrypted notes**: the data files of Marbles (`.mbls`), the encryption, the login page, Note Management (the main menu, the lists of entries and the notes in the editor), the merge and export tool, backups of data files and the password generator (`:pw` in the editor) are removed. A `.mbls` file is an ordinary file in the file browser. With them went the settings `onlymode`, `stayloggedin`, `clipboardnotes`, `file`, `subdir` and `backup` (left out when the settings file is read), the Data files tab of the Jump menu, `:logout`, `:title` in the editor, and the commands of the main menu (`:language`, `:size`, `:bw`, `:number`, `:defaults` ...: their settings are on the Configuration tab of the start page). Bookmarks and jumps to data files, kept by Marbles in `bookmarks.txt` and `jump.txt`, are left out.
- **Start page**: the first tab is **Start**, with **New file** (`N`), **Open file** (`F`, the file browser), **New project** (`P`), **Open project** (`O`), the **Jump menu** (`M` or `Ctrl+O`), the **Quick guide** (`U`) and **Exit**. The start page is shown again when the file browser is closed. Commands: `:new name`, `:file` (`:open`), `:project name`, `:projects` and `:start`.
- **Projects**: a project is a folder in the **projects folder** (setting `projectsdir`, by default `Blyant` in your Documents folder; set on the General page of Configuration). New project makes the folder and shows it in the file browser; Open project lists the projects, with what each holds. New file makes the file in the directory the file browser was in last. A page for managing the files of a project is planned.
- **File browser**: it starts in the projects folder (or the home directory), and `:home` goes there. `E` (or `:projects`) shows the projects in a list, and the one picked in the pane with the focus (also while the place to copy or move to is selected).
- **Editor**: `:projects` (`:proj`) shows the projects in a list; the one picked is shown in the file browser, as a jump (changes that are not saved are asked about first).
- **New files are Markdown**: a new file whose name has no extension gets `.md` (`chapter 1` is `chapter 1.md`): `N` and `:new` in the file browser, New file on the start page, and `:new` in the editor. A name that starts with a dot (`.gitignore`) is kept as it is.
- **The list of colors** (the colors of a scheme, of a favorite, a bookmark or a folder): each color has a letter that picks it at once, as the choices of the start page: `A` Black ... `U` White (leaving out `g` `j` `k` `l` `q`, which the list uses), and `X` for _[Default]_. `1` to `9` select the first nine colors.
- **Completing words**: the words of the Markdown list and of the list for all text in a new `completions.txt` start with `/`, so they are not offered while you write prose (`co` no longer offers a code block): `/h1` to `/h6` (headings), `/bold` (`**$0**`), `/italic` (`*$0*`), `/bolditalic`, `/strike`, `/inline` (code in a line), `/quote`, `/list`, `/numbered`, `/task`, `/done`, `/code`, `/table`, `/hr`, `/link`, `/image`, `/url`, `/footnote`, `/footdef`, `/frontmatter`, `/comment`, `/note`, `/warning`, `/todo` and `/lorem`. The word `JavaScript` is in the JavaScript list. A file made before keeps its lists. When the whole word of a completion is typed (`/bold`, with `/bolditalic` shown too), `Tab` completes with it at once. A completion is shown with `...` where the cursor goes (`**...**`, `<div>...</div>`), so one of marks only can be read. Completing is off from the start, and turning it on (`:complete`, or Configuration > Editor) makes the file.
- **Startup**: `startmode` is `select` (the start page) or `editor` (the file browser); `notes`, of Marbles, shows the start page.
- **Help, guides**: the help, the quick guide and the short guides tell of files and projects; the Note Management guide is now the **Projects guide**. The guides are `Guide-to-start-page.md` (the start page, projects and the file browser) and `Guide-to-jump-menu.md` (the Jump menu, color schemes and logos).
- **Its own data**: when the program directory cannot be written to, Blyant keeps its data in `Blyant/data` in the user's application data (Marbles uses `Marbles/data`), so the two programs can be used side by side.
- **Language files** start with `# Blyant: name (code)`.
- The history of changes before this is that of Marbles, found in its own repository.
